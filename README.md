# Quick View Drafter 2.0

Solar Project Quick View — Interactive tool for solar project form data extraction, drafting calculations, length unit conversions, and TNB bill address extraction.

## Features
- **Project Quick View**: Upload Excel project forms (.xlsx / .xls) to automatically extract and display customer details, system sizing, PV modules, Inverter specifications (with Inverter Quantity, MPPT Number, Max Output Current), Battery storage, and Section 6 Add-On equipment (Busbar Combiner Box, Optimizer, Ballast, RSD, Battery Stand).
- **Calculator**: Engineering calculator for on-the-fly solar drafting calculations.
- **Length Unit Converter**: Convert between mm, cm, m, inch, feet, and yard.
- **TNB Bill PDF Address Extractor**: Extract premise addresses from TNB bills.
